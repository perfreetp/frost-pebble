# 风筝扎制教学与考核平台

SolidJS + three.js 实现的风筝扎制教学/考核单页应用,数据通过 `localStorage` 持久化,内置可重置的演示数据。

## 启动

```bash
npm install
npm run dev      # 开发服务器
npm test         # 核心逻辑冒烟测试(确定性/覆盖保留/校验/评分/演示数据,共 102 项断言)
npm run build    # 类型检查 + 生产构建
```

顶栏可切换 **老师端 / 学员端**(演示环境,学员端底部可切换学员身份)。

## 四个界面

| # | 界面 | 角色 | 能力 |
|---|------|------|------|
| 1 | 出题布置 | 老师 | 按骨架类型、竹条数量、翼展、蒙面分片数、允差创建任务,查看提交进度、删除任务 |
| 2 | 三维制作台 | 学员 | 按参数+种子确定性生成骨架与蒙面;拖拽编辑竹条/接缝/提线点;调弧度;实时校验标红;提交;查看分数、评语、错题记录;导出图纸/清单 |
| 3 | 复核评分 | 老师 | 只读三维复核(超差标红)、逐项打分(默认带出自动分)、写评语、退回重做、查看累计错题、导出作品 |
| 4 | 班级统计 | 老师 | 按班次查看提交率、平均分、各错误类型出现次数条形图、学员明细 |

## 关键设计

### 确定性生成(`src/lib/generator.ts`)
- 随机源为 mulberry32,每个几何点用 `hash(seed, 稳定id)` 派生独立随机流 —— **同一种子任意次生成结果完全一致**,且与竹条数量、调用顺序无关。
- 四种骨架(板式菱形/板式六边形/硬翅沙燕/软翅)各自定义核心竹条与候选竹条,按目标竹条数有序补充,数量严格受 `TYPE_SPEC` 上下限约束。

### 手动修改保留(`Overrides`)
学员的所有手动操作都不直接改基准几何,而是以稳定 id 为键存成覆盖项:
- `stripOffset` 竹条平移偏移、`curvature` 弧度、`seamOffset` 接缝偏移、`bridleKnot` 提线点。

换参数重新生成时,先按新参数重建基准,再按 id 重新套用覆盖项 —— 挪过的竹条、改过的接缝在新骨架上继续保留;对应 id 消失(竹条被减没)时覆盖项静默留存,加回来后重新生效。

### 校验与评分(`src/lib/validation.ts`)
- 校验项:竹条数量、翼展尺寸(含偏差 mm)、分片数、成对竹条左右对称、竖脊居中、接缝对称、绑扎连接性(端点 22mm 内须搭上另一根竹条)、翅条弧度区间、提线点居中性/前后距离/附着点。
- 超差项带 `targetId`,三维视图中对应竹条/接缝/提线点**标红**,右侧列出每项偏差值(mm)。
- 自动评分百分制:参数符合度 40(数量 10 + 翼展 18 + 分片 12),骨架合理性 60(对称 22 + 连接弧度 18 + 提线 20)。老师复核可逐项改分。

### 三维交互(`src/three/KiteScene.ts`)
正交相机 + OrbitControls;射线拾取竹条(管状体)、接缝球、提线汇交点;竹条/接缝在蒙面平面(x-y)内拖拽,提线点在竖直面(x-z)内拖拽;拖拽期间禁用轨道控制器,松手恢复。

### 导出(`src/lib/exporter.ts`)
- **SVG 图纸**:毫米单位、含蒙面分色、骨架(超差红色虚线)、接缝、提线、翼展尺寸线。
- **CSV 参数清单**:任务参数、每根竹条端点/长度/弧度、接缝坐标、提线坐标(带 BOM,Excel 直接打开)。
- **JSON 快照**:完整 task + kite 状态。
