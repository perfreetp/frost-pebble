# 像素工坊 · 康复器械抠图合成工作台

给康复器械厂商做电商主图和目录册的抠图/合成工作台。客户下单建项目，制作员逐张实拍图抠图修边、挑背景下合成，主管按边缘毛刺与色温偏差审核，通过后按项目打包导出透明底与合成图。

所有抠图、修边、合成、质检全部由 **WebGPU 计算着色器** 实时完成，没有服务端，数据存在浏览器 IndexedDB。

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build && npm run preview
```

需要 Chrome / Edge 113+（要求 WebGPU）。首次打开会生成演示素材（实拍图、背景库、两个项目、12 个条目并渲染审核快照），约 4 秒。

## 角色与流程

顶栏切换三个身份，同一份数据三种视角：

| 身份 | 能做什么 |
| --- | --- |
| 客户（苏芃） | 新建项目：产品型号、用途场景、交付张数、截止时间、备注 |
| 制作员（林知遥） | 建条目（每条一张实拍图）、进制作台抠图修边、挑背景下合成、提交审核；导出透明底/合成图 |
| 主管（钱立群） | 审核台按条对比边缘毛刺与色温偏差，通过或退回并写意见 |

状态机：`待制作 → 制作中 → 待审核 →（退回）返工中 → 待审核 → 已通过`。退回次数累加到条目（`reworkCount`），看板与交付页都按条目汇总。审核中和已通过的条目在制作台锁定，点击任何编辑控件都会提示原因。

## 抠图链路（`src/gpu/shaders/`）

一张实拍图进来后分三层蒙版，每层对应调色师的一种操作：

```
raw（初抠）      matte_distance → matte_refine → matte_cleanup
painted（修边）  raw + 每一笔笔刷（stroke.wgsl，ping-pong）
shaped（成稿）   painted + 羽化/硬度轮廓（matte_harden）
```

- **背景估计**（`bg_estimate` / `bg_refine` / `solveBackgroundField`）：边框环上做 16³ 直方图找主色，再在 GPU 上测该色簇的均值与逐通道标准差。同时 CPU 解一张 16×16 的背景场——每格取亮部四分位，暗格按邻居扩散，再两次盒式模糊——用来表示棚布的光渐变，避免把亮的那半边背景误判成主体。
- **matte_distance**：像素与「本格背景色」按实测标准差归一化后求距离，3σ=1.0。阴影落在棚布上时色相相同、亮度更低，且局部平滑，因此被判回背景——否则每一张都要手工擦掉产品投影。
- **matte_refine**：5×5 加权均值压噪；局部对比度高时把边缘向外拉（找回细杆、辐条、线缆）；不支持任何邻居的弱 alpha 与无轴向支撑的细环（背景投影的抗锯齿边）被削掉。
- **matte_cleanup**：环采样要求「四周全是不透明」才补洞，所以白塑料压在白棚上的镂空能补，而产品外侧的影子不会被填进主体。
- **matte_harden**：按蒙版自身轮廓重新做一次 smoothstep，羽化半径与硬度滑杆落到实处。导出用的 alpha 与预览是同一张。
- **stroke.wgsl**：一次拖动只派一个笔刷（分段 ping-pong），按笔画包围盒派发 workgroup，长笔也不贵。拖动时走 liveBase/liveRes 双缓冲，只在落笔时提交到文档。

## 合成（`composite.wgsl`）

一个计算着色器四种显示模式：蒙版（棋盘格）、选区（品红罩住被丢弃区域）、合成、原图（按住空格或按钮对比）。

- **色温校正**：`color.ts` 用黑体轨迹近似求主体与背景的 CCT，按通道算增益（夹在 0.82–1.22，避免把产品染成背景色），只作用在主体上并保亮度。
- **投影**：蒙版模糊两次（`shadow_blur`）后按光向位移，接触阴影与投影分开计算。
- **背景**：库选或上传，支持缩放与平移。

## 质检（`metrics.wgsl`）

审核台的两个数字都由 GPU 原子累加得到的，不需要把 4K alpha 读回内存：

- **边缘毛刺**：剪影边界像素上带饱和色（背景溢色）的比例；羽化带单独计并降权。
- **色温偏差**：主体像素（被蒙版覆盖的部分）的平均色温与背景色温之差。

提交审核时把当前合成图渲染成快照存进条目，退回后若重新编辑会重新出图，主管永远看到的是当前参数对应的图。

## 导出

- 单条：透明底 PNG（直通 alpha + 边缘去色 `decontaminate`）、合成图。
- 项目交付页：把所有已通过条目重渲染进内存，`fflate` 打成 zip，内含 `transparent/`、`composite/` 与 `manifest.txt`（型号、尺寸、返工次数、所用背景）。

## 目录

```
src/
  gpu/engine.ts          设备、纹理、pipeline、三层蒙版同步与导出
  gpu/shaders/*.wgsl     背景估计、距离、收敛、补洞、羽化、笔刷、合成、投影、质检、导出
  lib/store.ts           Solid store + IndexedDB 持久化 + 项目/条目/审核动作
  lib/color.ts           sRGB/线性、CCT 近似、色温增益、边缘指标
  lib/proof.ts           审核快照与质检数据的统一构造（制作台与种子共用）
  views/                 BoardView（看板）、StudioView（制作台）、ReviewView（审核台）、DeliverView（交付）
  seed/                  演示用的程序化实拍图与背景库（2D canvas 绘制）
```

演示数据版本号在 `src/lib/store.ts` 的 `SEED_VERSION`；改素材后递增即可让老浏览器重新播种。
