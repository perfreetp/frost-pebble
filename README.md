# 陵园墓区布置与施工工单系统

Vue 3 + Canvas 2D + OffscreenCanvas 的陵园墓区布置与施工工单管理系统（纯前端，数据存 localStorage）。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 构建
npm run preview    # 预览构建产物
```

## 五个页面（完整业务闭环）

1. **前台接单** — 录入家属信息、逝者、家属需求，选择墓区/排/号（自动校验占用）与碑型、刻字内容，生成工单。
2. **布置编辑器** — 俯视布置：
   - 物件：墓碑 / 石栏 / 绿植 / 供桌，可拾取拖拽，带旋转、缩放手柄；
   - 越出墓区、压占相邻墓位、堵住通道时物件**立即变红**提示；
   - 松手自动吸附 **30cm 网格**并对齐排距方向（90°）；
   - 底图层 / 物件层 / 标注层分别用 **OffscreenCanvas** 离屏渲染再合成，底图（上千墓位）只在视图变化时重绘，拖拽不卡；
   - 滚轮缩放、拖动平移、Delete 删除；
   - 定稿生成俯视图（可导出 PNG）与物料清单：**石材块数、绿植棵数、刻字字数**。
3. **工单排班** — 物料清单随工单进入待派工列表；主管按师傅**手艺（技能）与在手工单数**分派并设工期；师傅施工后上传完工照片、提交质检；打回工单可重新进入编辑器改布置图。
4. **质检** — 对照俯视图与完工照片执行抽查（合格 / 不合格 / 免检），**抽查率要求 ≥30%**，不足给出告警；不合格填整改项打回并**计一次返工**，改完须重新提交审核。
5. **看板** — 按师傅统计完成量、返工率、平均工期；**超期工单标黄**。

## 状态流转

```
待布置 →(定稿)→ 待派工 →(派工)→ 施工中 →(传照片提交)→ 待质检 →(合格/免检)→ 已完成
                                      ↑                  │
                                      └──(不合格打回,计返工)←──┘
                                      打回后可改布置图，需重新定稿并重新提交审核
```

## 技术要点

- `src/editor/engine.js` — 三层离屏渲染（OffscreenCanvas，不支持时回退普通 canvas）
- `src/editor/geometry.js` — OBB/AABB SAT 碰撞检测、30cm 网格吸附、直角对齐
- `src/store.js` — 响应式数据层 + localStorage 持久化 + 演示种子数据（3 个墓区，松鹤苑 30×40=1200 墓位）
- `smoke.mjs` / `flow-test.mjs` — 基于 puppeteer-core 的页面冒烟与全流程测试（需本机 Chrome，先 `npm run preview` 再 `node flow-test.mjs`）

点导航栏「重置演示数据」可恢复初始种子数据。
