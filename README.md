# 苗圃出圃档案加工系统 · Nursery Dispatch Archive

面向苗圃技术员、质检员与负责人的出圃档案加工与留存系统。SolidJS 负责界面与状态，Phaser 3 负责加工台画布。

## 启动

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 产物到 dist/
npm run preview
```

首次打开会生成一套演示数据（5 个批次、5 张样苗照片、5 个已合成版本、3 份抽检记录），可直接走完整流程。数据存放在浏览器 IndexedDB（图片较大，localStorage 仅作回落）。总览页底部可一键重置演示数据。

## 业务流程

1. **批次建档**（技术员）：品种、品系、苗龄、地径区间、苗高区间、出圃数量、苗床 → 自动生成编号 `MC-年份-品种-序号`。
2. **样苗拍照**：可开摄像头实拍、导入本地照片，或用「演示样苗生成器」合成一株带枝叶与杂物的样苗（无实拍条件时验证流程）。
3. **加工台**（Phaser 画布）：
   - **自动初抠**：以照片左右边缘底色按行插值建模，按色距容差判定前景，连通域剔除噪点，边缘羽化。容差滑块松手后重新初抠。
   - **画笔补回枝叶** / **橡皮擦除杂物**：笔触以归一化坐标存储，与照片分辨率无关；空格切换工具，可逐笔撤销。
   - **换背景**：标准棚拍 5600K、清晨圃地 4600K、阴天户外 7000K、温室苗床 5200K，场景自带光位与地面材质。
   - **投影**：接地接触阴影 + 轮廓投影，方向随场景光位，强度 0–100% 可调。
   - **实测尺寸标定**：输入苗高 / 地径，规格图按蒙版外接框换算比例绘制高度刻度与地径卡尺。
   - 同时产出 **规格图**（交付用）与 **查验图**（10cm 网格 + 刻度 + 卡尺 + 待查验章），均为 1200×1600。
4. **版本**：每次改动（换背景、调投影/羽化、补笔、改尺寸）自动留一版；也可手动存版。加工台可**叠加上一版**——青色为本版笔触、红色为本版擦除处，与当前照片逐像素对齐。
5. **版本比对**：时间线选择基准 A / 对比 B，支持分割、叠加、差异、并排四种视图，并给出参数差异摘要。
6. **抽检判定**（质检员）：逐株录入地径与苗高，系统按批次区间判定；达标率低于阈值（默认 90%）判为不达标，须填写批注原因，系统列出逐株原因汇总。
7. **出圃报告**（负责人）：批次信息、规格图 + 查验图、抽检明细表、达标率、版本沿革、三方签名位；可打印/存 PDF、导出独立 HTML（图片内嵌）、导出抽检 CSV。
8. **归档与检索**：仅「已有版本 + 抽检达标」可归档，归档记录出圃月份；档案检索支持品种、苗龄、达标状态、出圃月份 + 关键字组合筛选，点击行查看同批次全部历史版本。

## 目录

```
src/
  index.tsx           入口（先初始化 IndexedDB 再挂载）
  App.tsx             hash 路由
  styles.css
  components/         Shell 布局、通用 UI、Phaser 挂载容器、图标
  pages/              总览 / 建档 / 拍照 / 加工台 / 版本 / 抽检 / 报告 / 档案 / 规范
  phaser/bench.ts     Phaser 加工台场景（画笔、蒙版、投影、叠加）
  lib/
    types.ts          领域模型与场景预设
    store.ts          Solid store、持久化、编号、归档、版本
    store-eval.ts     抽检判定（纯函数，无 DOM 依赖）
    cutout.ts         自动初抠
    compose.ts        规格图/查验图合成
    mask-engine.ts    笔触图层与蒙版合成
    sample.ts         演示样苗生成
    seed.ts           演示数据（用真实合成管线生成成图）
    idb.ts            IndexedDB 单记录快照
```

## 说明

成图为规格示意，不作为法定检验依据。自动初抠依赖颜色边缘模型，遇到与背景同色的枝叶或强逆光照片，请配合画笔手工修补后再存版。
