# 方言调查档案与区划图加工系统

基于 **Svelte + three.js** 的纯前端单页应用,数据持久化在浏览器 IndexedDB,无需后端。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 功能流程

1. **发音人建档** — 自动编号(F年份-序号),录姓名、年龄、乡镇、音系条目数、录音条目、音系特征。
2. **批次记音表** — 按批次关联发音人,挂接原始记音表文件(存入 IndexedDB,可下载)。
3. **区划加工台** — three.js 三维地形底图(程序化高程 + 乡镇界 + 公里网格),上层 Canvas2D 矢量层:
   - 画同音线(虚线)、画分区路径、放调查点;
   - 分区路径支持**并集 / 差集 / 交集**布尔运算,合并为完整分区;
   - 调查点自动**吸附**乡镇界(青圈)与网格交点(蓝圈),阈值 2.5km;
   - **Ctrl+Z / Ctrl+Shift+Z** 逐步撤销重做,工作稿自动保存。
4. **版本比对** — 提交新版本时与上一轮分区比对:绿色=新增、红色=删除、黄色标签=移动边界;**差异面积超过 5% 必须填写变更说明**才能提交。
5. **审核归档** — 预览成果报告,审核通过后版本归档并生成调查成果报告(可打印/导出 PDF),也可驳回。
6. **成果检索** — 按方言区 × 乡镇 × 音系特征 × 年份任意组合过滤发音人与归档报告。
7. **数据设置** — 可导入自定义乡镇界 GeoJSON(0–100 平面公里坐标)替换内置模拟数据。

## 技术要点

- `src/lib/terrain.js` — three.js 顶视正交相机,视图状态 `{cx, cy, k}` 与 Canvas2D 层共享,保证两层严格对齐。
- `src/lib/geo/boolean.js` — 基于 `polygon-clipping` 的并/交/差,MultiPolygon 结构。
- `src/lib/geo/diff.js` — 新旧分区对称差计算差异面积占比;按名称匹配分区,质心位移 >1.5km 或面积变化 >5% 判定为移动边界。
- `src/lib/history.js` — 快照式撤销/重做栈。
- `src/lib/db.js` — IndexedDB 封装,五个 store:informants / batches / versions / reports / kv。
