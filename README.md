# 电梯轿厢装潢配置器

面向电梯装潢公司的轿厢方案实时配置工具:TypeScript + three.js,替代"拍照片加贴图"的传统出方案方式。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
```

## 功能

- **新建项目**:选梯型(乘客梯/载货梯/家用梯),输入内宽/内深/内高(mm)与载重(kg),选开门方式(中分/双折/旁开)
- **冲突校验**:自动校验操纵箱、扶手与门机/门垛收纳区的干涉,冲突壁板在 3D 视图中红色高亮并给出文字原因;扶手点选时若压到操纵箱直接拦截并回退
- **材质配置**:天花板、地板、三面壁板、门套独立选材质(拉丝不锈钢/木饰面/岩板),每种带防火等级、单方重量、单价、供货周期
- **增重累计**:按净面积自动累计装潢增重,超过额定载重 5% 红色告警提示减配
- **吊顶**:平板/发光顶/格栅三种形式,按面积给出灯具数量与照度建议(按梯型)
- **扶手**:按壁面、高度、长度点选
- **实时预览**:白模/效果图一键切换;办公/住宅/地库三套光照预设;金属材质带环境反射(PMREM 环境贴图),木纹、岩板为程序化分区贴图
- **方案清单**:实时汇总材质面积、增重、报价、交期
- **导出**:报价单页面(可打印/存 PDF)、可再导入的方案 JSON 文件
- **同型号套用**:配置自动按"梯型+净尺寸"存档,同型号轿厢一键套用历史配置

## 目录结构

```
src/
  types.ts            数据模型
  data/catalog.ts     材质/吊顶/扶手目录(防火等级、单重、单价、周期)
  logic/validation.ts 门机/操纵箱/扶手冲突校验
  logic/pricing.ts    面积、增重、报价、交期、灯具照度计算
  scene/textures.ts   程序化贴图(拉丝不锈钢/木纹/岩板)
  scene/cabin.ts      three.js 轿厢场景与三套光照预设
  ui/panel.ts         左侧配置面板与右侧清单
  ui/quote.ts         报价单导出、方案文件导入导出
  state.ts            同型号模板存取(localStorage)
  main.ts             入口与事件装配
```
