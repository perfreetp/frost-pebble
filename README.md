# 点画字坊 · 字形档案与生成平台

字体设计工作室的内部工作台：给每个字建档编号、按参数生成笔画、拖动端点手工微调、版本并排比对、审稿打点，最后验收归档并出字样报告。

技术栈：Svelte 5（runes）+ Vite + TypeScript + WebGL2。字形几何完全在前端计算，档案保存在 `localStorage`。

## 启动

```bash
npm install
npm run dev        # http://localhost:5173（或 vite 自动分配的端口）
npm run build      # 产物在 dist/
```

## 四个界面

| # | 界面 | 做什么 |
|---|------|--------|
| 01 | 档案 | 建档（选骨架、字库、字重、骨架来源、初版参数与备注，自动编号 `GF-YYMM-NNNN`）；按字库 / 字重 / 状态 / 建档日期 / 关键词多条件检索；查看大样、规格、版本轨迹、审稿记录与初版样张 |
| 02 | 生成台 | 字重、粗细对比、倾斜角度、圆角半径、收笔形态、种子实时生成；同一档案换参数后只有非锁定笔画重算；拖动端点即锁定该笔，改参数时保持不变；保存即出新版本 |
| 03 | 版本比对 | 两版并排 + 叠加幽灵轮廓；重心、字面宽高、着墨率逐项对比，偏差 > 3% 的指标单独标红列出 |
| 04 | 审稿归档 | 审稿人对着字面打点写意见（结构 / 笔画 / 重心 / 间距 / 收笔 / 一致性）；设计员逐条回复并把状态从「待处理」改为「已处理」；全部处理完后验收归档，自动生成可打印的字样报告 |

## 确定性生成

- `mulberry32` + FNV-1a 哈希，种子只驱动每笔中心线节点的抖动，抖动包络在端点归零。
- 同一 `{种子, 字重, 对比, 倾斜, 圆角, 收笔}` 必得同一中间线；生成台有「同种子连生两次，逐字比对」按钮做在线校验。
- 指纹 `fingerprint` 由参数与最终笔画数据哈希得到，版本记录中携带。

## 色层约定

- 墨色实心：字形轮廓。
- **朱色 1px 轮廓**：被手工锁定（拖动过端点）的笔画。
- 朱色虚线：重心 / 基线等辅助线。

## 几何管线

1. 骨架库（`src/lib/skeletons.ts`）以 UPM 1000 em 坐标记录每笔中心线。
2. `generator.ts` 按种子抖动节点 → `strokeOutline()` 沿程变宽（按笔画类型与对比度）→ 圆形/平切/尖/喇叭/斜切端帽 → 圆角。
3. `geometry.ts` 用 `polygon-clipping` 合并所有笔画，`earcut` 三角化，上传 WebGL2 绘制；同时导出 SVG path 给缩略图与报告。

