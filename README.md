# 改色贴膜预览工坊（Car Wrap Studio）

门店汽车改色贴膜的浏览器预览与报价工具。TypeScript + three.js 实现，纯前端、零后端，方案保存在浏览器 localStorage，刷新不丢。

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://127.0.0.1:5173
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产构建
```

无头浏览器冒烟/导出/材质测试（需本机装有 Chrome，脚本里可改路径）：

```bash
node scripts/smoke.mjs        # 渲染、交互、算料、持久化主流程
node scripts/export-test.mjs  # 图片拼图 / TXT 报价单 / JSON 方案导出
node scripts/material-test.mjs # 四类材质渲染 + 膜宽联动
```

## 三个界面

1. **车型与配色**：轿车 / SUV / 皮卡三种简化车身模型，轨道控制拖拽旋转、滚轮缩放，前 45°/正侧/尾部预设视角；亮面、哑光、电镀、变色龙四类材质，20 色预设色卡 + 自定义取色，金属度/粗糙度滑块；双拼模式下点击车身分块（或分块列表）给引擎盖、车顶等大面单独换色。
2. **接缝与用料**：按膜卷宽度自动判断超膜宽分块，3D 场景用红色标出接缝并提示走向（藏在棱线/B 柱/格栅等位置）；逐块给出开槽/拼接提示、下料条数、每条尺寸、拼接条数、下料面积与耗损率；按颜色/材质汇总平米数、用膜长度、拼接条数与综合耗损。
3. **报价分享**：四类材质门店单价与施工费可配置，自动生成报价单；导出三张视角图 + 带报价信息的拼图 PNG、TXT 报价单、JSON 方案文件；支持快照存档、JSON 导入。

## 工程结构

```
src/
  types.ts            领域类型与可序列化 AppState
  storage.ts          localStorage 持久化
  store.ts            状态容器（订阅/更新/自动保存）
  calc.ts             膜宽分片、拼接、耗损、报价计算引擎
  data/
    vehicles.ts       三种车型的车身分块工程数据（面积/尺寸/开槽/接缝走向）
    presets.ts        四类材质参数与预设色卡
  three/
    materials.ts      贴膜材质工厂（含变色龙 onBeforeCompile 着色器）
    geometry.ts       三种简化车身几何、可点选分块、红色接缝标记
    scene.ts          场景/相机/轨道控制/射线点选/截图
  ui/
    screen1.ts        车型与配色
    screen2.ts        接缝与用料
    screen3.ts        报价分享（导出/快照/导入）
    dom.ts            DOM 构建助手
```

## 算料口径

- 分块展开宽度超过膜卷宽度（默认 1.52m）时按 `ceil((宽-搭接)/(膜宽-搭接))` 条下料，条间接搭，拼接条数 = 条数 − 1。
- 每条下料长度 = 分块长度 + 包边预留（默认 0.08m）。
- 下料毛面积 = 条宽 × 条长 × 条数；耗损率 = (毛面积 − 净贴膜面积) / 毛面积。
- 同颜色同材质（含金属度/粗糙度）的分块合并为一个用料组，按门店单价 × 下料面积计费，加一口价施工费得报价总计。

面积与分块尺寸为内置经验值，可在 `src/data/vehicles.ts` 按门店实际车型校准。
