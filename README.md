# 刺绣工坊针法动画课件系统

面向刺绣教学的 2D 骨骼动画课件系统：老师建针法课目、拆分部件绑骨、在时间轴上制作走针示范动画；学员在派给自己的课目上练习提交，系统自动核对关键帧数量、时长误差与循环闭合，老师逐帧复核打分。

技术栈：**SolidJS + TypeScript + WebGPU（WGSL）+ Vite**，数据持久化使用 IndexedDB（含图片 Blob 分库存储），无后端依赖，纯前端可离线运行。浏览器不支持 WebGPU 时自动降级到 Canvas2D 渲染。

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5180
npm run build      # 生产构建
npm run preview    # 预览生产构建
```

测试：

```bash
npm run test:unit  # 动画数学/缓动/自动核对的 21 项单元断言
npm run test:e2e   # Playwright 端到端流程（需先启动 dev 或 preview，可用 BASE_URL 指定地址）
```

## 四个界面

1. **老师课目管理（TeacherCourseList）**：新建/编辑针法课目（名称、难度档位、要求时长、必须出现的关键动作、学员派发），卡片显示已交/未交人数与待复核/已评分/已退回数量；进入备课台上传底稿与手/针/线/绷架部件、拖拽关节绑骨、制作示范动画。
2. **动画编辑器（AnimationEditor，老师备课台 / 学员练习台 / 逐帧复核三模式）**：
   - 画布上拖拽关节完成绑骨，部件按关节枢轴跟随；支持父子骨骼、图层显隐与 z 序。
   - 时间轴打关键帧（位置 + 旋转），每帧之间的插值曲线可用贝塞尔控制点**单独调节缓入与缓出**，附线性/缓入缓出/回弹等预设。
   - 同一动作可按帧区间复制到其他位置（`copyActionRange`）。
   - 24fps 循环播放、播放头逐帧 scrub、动作区间色带。
3. **学员主页（StudentHome）**：只列派发给自己的课目；练习台自动存草稿，提交前预检，提交后生成版本号；历史版本表对比各版关键帧数/时长偏差/扣分项，退回作业显示具体扣分原因与老师评语后可重做。
4. **老师复核与成绩汇总（TeacherReview）**：逐帧查看学员动作（只读编辑器），对照自动核对报告打分、写评语或退回（退回必须填写原因）；汇总页按入门/进阶/高级三档统计平均分，并给出跨课目常见错误排行与累计扣分。

## 自动核对规则（`src/lib/anim.ts: autoCheckSubmission`）

- **关键帧数量**：低于「关键动作数 × 2」下限扣 10 分。
- **时长误差**：实际末帧与要求时长相差超过 **5 帧**扣 15 分（恰好 ±5 帧不扣）。
- **关键动作**：每个必须出现的动作在其帧区间内没有关键帧，每项扣 20 分。
- **循环首尾闭合**：比较第 0 帧与末帧各关节的位置（容差 6px）与角度（容差 8°），不闭合扣 15 分。
- 空作品直接 0 分；满分 100，逐项扣分后封底 0 分。老师评分独立于自动分，可结合评语调整。

## 渲染管线（`src/lib/renderer.ts`）

- WebGPU 路径：每个部件一张纹理，实例化四边形经 `mat3x3` 仿射矩阵（平移/绕枢轴旋转/缩放）在 GPU 上合成，uniform 按 WGSL 规则做 vec4 列填充（48B 步长），alpha 混合。
- Canvas2D 降级路径：相同的枢轴旋转语义，保证无 WebGPU 环境（如部分虚拟机、旧浏览器）功能完整。

  smoke-test.ts         纯逻辑单元测试
