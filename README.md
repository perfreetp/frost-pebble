# 霓虹招牌定制预览工作台

浏览器内运行的门店霓虹招牌设计与发光效果预览工具。TypeScript + 原生 WebGL2，不依赖任何现成场景编辑器，仅用 `opentype.js` 解析字库。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览构建产物
npm test           # 纯逻辑单元测试（vitest，18 个用例）
```

## 功能与需求对照

| 需求 | 实现 |
| --- | --- |
| 招牌尺寸与安装墙面 | 左面板设置墙宽/墙高（mm），网格间距可调 |
| 墙面传本地照片当背景 | FileReader → dataURL → WebGL 纹理，按环境光自动压暗；方案与客户文件均内嵌 |
| 单色 / 双色灯管 / 亚克力发光字 | 三种 `ElementKind`；双色按周期交替，亚克力由字库描边轮廓三角化 |
| 灯管按折弯路径绘制 | 折线顶点 + 每折角折弯半径，圆弧用真实几何（切线裁剪 + 弧长修正） |
| 自动吸附网格和已有笔画端点 | `core/snap.ts`，端点优先于网格，绘制时排除自身防自吸 |
| 单根超 2.4m 提示加接头 | `connectorJoints`，按 2.4m 分段统计接头数，右侧告警 + 施工图标记 |
| 折角半径 < 直径 2 倍标红 | 统计驱动 `badCornerMap`，GL 丝带局部变红 + 叠加层红圈 + 告警列表 |
| 字库生成描边路径再手调笔画 | opentype 解析 TTF（内置 Roboto，可上传本地字体），曲线自适应细分；顶点可拖拽（带吸附） |
| 右侧实时发光效果 | 独立 WebGL2 画布，与主画布共享同一套网格数据 |
| 白天 / 黄昏 / 深夜三套环境光 | `ENVIRONMENTS` 预设，切换只改 uniform（实测 <1ms） |
| 泛光强度、光晕半径可调 | HDR 半浮点帧缓冲 + 亮度提取 + 两轮双向高斯 + ACES 色调映射 |
| 换场景不卡过 1 秒 | 环境切换走 uniform 快路径；40 元素全量重建实测 4–12ms（SwiftShader 软件渲染） |
| 统计灯管总长 / 接头数 / 变压器数 / 带载余量 | `core/stats.ts` 实时计算 |
| 变压器超载给换大一号建议 | 贪心装箱 + 容量档选型，超载时输出建议 VA |
| 按材料单价算报价 | 单价可在左面板修改，报价明细表实时更新 |
| 导出带尺寸标注的施工图 | SVG，含总宽/总高标注、折弯告警、接头位置、统计摘要 |
| 导出材料清单 | CSV（BOM + 报价 + 电气统计），Excel 可直接打开 |
| 方案存浏览器本地 | IndexedDB（失败回退 localStorage），自动保存 + 手动保存 |
| 导出一个文件发客户 | 单个自包含 HTML，内嵌方案数据与零依赖 WebGL2 查看器，双击即看，可切环境/调泛光 |

## 架构

```
src/
  types.ts                 数据模型（全部长度单位 mm）
  core/
    geometry.ts            向量、折弯圆弧、路径实长、包围盒、多边形面积（纯函数）
    snap.ts                网格/端点吸附、命中测试
    stats.ts               接头规则、半径告警、变压器选型装箱、报价
    font.ts                TTF 加载与文字轮廓生成（两遍缩放到真实字高）
    defaults.ts            环境预设、默认参数、工厂
    storage.ts             IndexedDB/localStorage 持久化
  render/
    shaders.ts             GLSL ES 3.00（场景/泛光/模糊/合成）
    mesh.ts                灯管丝带（含圆头、双色、标红）、亚克力耳切三角化
    NeonRenderer.ts        HDR FBO 泛光链、相机、照片纹理
  editor/
    store.ts               状态 + 撤销/重做 + 订阅
    controller.ts          指针交互、绘制、吸附、拖拽、平移缩放
    overlay.ts             2D 叠加层（网格/手柄/吸附提示/标注）
  export/
    exporters.ts           SVG/CSV/JSON/客户 HTML
    client-viewer.ts       内嵌进客户文件的零依赖查看器源码
  ui/                      样式
  main.ts                  装配
```

## 关键设计

- **HDR 泛光**：场景渲染到 `RGBA16F` 浮点缓冲，发光体以 ~2.6 倍线性色做加法混合；亮度 >1 的部分进半分辨率泛光链，最后 ACES 色调映射回 LDR，因此白天霓虹不刺眼、深夜有明显光晕。
- **折弯半径是真实几何**：不是视觉圆角，长度统计按「折线总长 − 2×切线裁剪 + 弧长」计算，报价的用米数与施工图一致；半径超过相邻段时自动截断防止翻转。
- **规则与渲染解耦**：所有工程规则（接头、半径、变压器、报价）都是不依赖 DOM/WebGL 的纯函数，vitest 覆盖；UI 与渲染只消费结果。
- **客户文件零依赖**：导出的 HTML 把项目 JSON 和一份精简 WebGL2 查看器（含相同的泛光管线）全部内嵌，无网络请求、无外部资源，照片以 dataURL 内联，可直接微信/邮件发送。

## 操作速查

- 灯管工具：左键加点（自动吸附），右键撤销上一点，双击或 Enter 完成，Esc 取消
- 选择工具：拖元素移动，拖顶点改形，Delete 删除，Ctrl+D 复制，Ctrl+Z / Ctrl+Shift+Z 撤销重做
- 画布：滚轮缩放（以指针为中心），中键或右键拖动平移
