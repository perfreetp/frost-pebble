# 禾影工坊 · 作物拟人角色骨骼动画工作台

面向种子站科普动画的 2D 角色骨骼动画与农技审核工作台。动画师把作物拟人角色的**头 / 躯干 / 叶片 / 穗 / 根须**拆成零件导入，在画布上拖关节搭父子骨架，设好绑定姿态后回时间轴给位移、旋转、缩放打关键帧；农技审核员在画面上点位置写批注，制作方逐条回复，未处理完的批注挡住定稿；两个版本可以并排比对差异帧。

技术栈：**原生 TypeScript + Web Components + PixiJS 8**（Vite 构建，无框架）。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

首次打开会生成 6 个演示项目（水稻 / 小麦 / 玉米 / 大豆 / 高粱，含超期、待审核、退回、已采用各状态）。数据保存在 `localStorage`，清空浏览器存储即可回到初始演示数据。

```bash
npm run typecheck  # tsc --noEmit
npm test           # 核心逻辑单测（缓动 / 骨骼解算 / 版本与审核流转）
npm run test:e2e   # Playwright 端到端（4 个界面主流程 + 导出校验）
npm run build      # 生产构建
```

## 四个界面

| 界面 | 路由 | 职责 |
| --- | --- | --- |
| 项目总览 | `#/projects` | 按**作物 / 集数 / 交付日期**分组，超期标红，状态计数与筛选，新建项目 |
| 动画工作台 | `#/animate` | 零件库、搭骨与变换、骨架层级、骨骼检查器、时间轴关键帧与缓动、导出 |
| 农技审核 | `#/review` | 画面批注（落帧）、逐条回复、定稿门禁、状态流转、流转记录 |
| 版本比对 | `#/compare` | 任选两个版本并排 / 叠加，差异帧带与跳转 |

顶部可在「动画师 / 农技审核」身份间切换，同一份数据、不同权限视图。

## 动画工作台

**零件与骨架**

- 左侧零件库列出内置的 5 类零件（程序化生成透明 PNG，可像导入素材一样使用）；拖 PNG 进零件库或点「＋ 导入」即可加入自定义零件，文件名含 `head/头`、`torso/躯干`、`leaf/叶`、`ear/穗`、`root/根` 会自动归类。
- 双击零件挂到当前选中骨骼，或在检查器「挂载零件」下拉里指定。
- 工具条切换三种模式：**选择**（拖关节位移、拖上方圆点旋转）、**搭骨**（先点父关节再点位置放子关节）、**批注**。
- 父子关系在检查器里可改，自动拒绝把骨骼挂到自己的子孙下，避免环路。

**绑定姿态**

- 每个骨骼都存一份 bind（X/Y/旋转/缩放）。「保存当前为绑定」把当前姿态写回 bind，「恢复绑定」把骨骼退回静置姿态。
- 绑定姿态随每个版本一起快照，导出时写入 `character.json`。

**锁定**

- 检查器或层级面板的「🔒 锁定」把骨骼设为不可拖动：画布上拖不动、检查器的数值框禁用、不能打关键帧，只有解锁后才能编辑。点击锁定零件会选中它（方便解锁）并提示原因，不会误改数据。

**时间轴**

- 每根骨骼三条通道：位移、旋转、缩放。工具栏「◆ 打关键帧」（快捷键 `K`）在当前帧为选中骨骼的三条通道都打帧；双击某条通道在该帧加单通道键。
- 关键帧可水平拖动改帧，拖动时有吸附与冲突保护。
- 每根曲线可在**缓入缓出 / 阶梯 / 贝塞尔**之间切换：选中关键帧或曲线段后点工具栏按钮，或在曲线段上右键弹出选单（贝塞尔可填 4 个控制点）。关键帧菱形按缓动着色，曲线段画出实际插值曲线。
- 播放头可拖动预览，播放条支持逐帧、循环播放；`空格` 播放/暂停、`←/→` 逐帧、`Shift+←/→` 跳 10 帧、`Home/End` 到首尾。
- 拖动骨骼时若该通道已有关键帧，会在**当前播放头帧**写入/更新关键帧（自动关键帧），保证所见即所得。

**交付导出**

- 「导出」选择版本（当前工程或某个已提交快照）、1×/2× 分辨率、是否附带零件 PNG。
- 交付包为 zip：`frames/frame_0000.png…`（逐帧透明序列帧，960×640 / 1920×1280）、`character.json`（骨架、父子关系、绑定姿态、每通道关键帧与缓动/贝塞尔参数）、`sequence.json`、可选 `assets/`、`README.txt`。
- 导出用独立的 Canvas 2D 渲染通路（不依赖 WebGL 回读），进度与日志实时显示。
- 「导入配置」可回读 `character.json`，骨架与曲线原样恢复。

## 审核与版本

**批注**

- 审核员点「写批注」后在画面上点位置写意见，批注自动挂到**当前播放头所在帧**（画面上有引线定位点，时间轴有编号标记，点击可跳帧）。
- 审核中新增批注会把项目从「待审核」打回「退回」。
- 制作方在审核台逐条回复，二选一：**✓ 标记已改** 或 **说明理由**（都必须有文字）。已处理的批注可重新打开；审核员可撤回自己写的批注。

**定稿门禁**

- 只要还有 `pending` 批注：工作台的「提交新版本」按钮弹窗禁用提交，审核员「通过并采用」按钮禁用，顶部持续显示「⛔ N 条批注未处理 · 不能定稿」。

**版本**

- 每次提交都会快照当前骨架与全部关键帧，版本号从已有最大值 +1 **连续递增**（v1 → v2 → v3…），不会因为删改而回退。
- 提交后状态自动流转到「待审核」。

**状态流转**

`制作中 → 待审核 → 已采用`，`待审核 → 退回 → 制作中`。每次流转都在 `activity` 里记录**操作人、身份、时间、前后状态与备注**，审核台底部「流转记录」逐条展示。

**版本比对**

- 任选两个版本作基线与对比，支持**并排**与**叠加**（半透明绿色叠影）两种视图。
- 逐帧比较骨骼的世界位移、旋转、缩放，超过阈值即标为差异帧；底部差异带用金色块标出，可点击跳帧或「跳到下一个差异帧」。
- 可单独导出基线版本的序列帧。

## 项目结构

```
src/
  core/
    types.ts        领域模型（Project / Bone / Keyframe / Annotation / Version / Activity）
    easing.ts       缓入缓出、阶梯、cubic-bezier 采样与曲线点
    rig.ts          矩阵解算、父子姿态、绑定、通道采样、版本差异帧
    store.ts        状态、种子数据、版本与审核工作流、流转留痕
    art.ts          程序化作物零件绘制（5 类作物 × 5 类零件）
    renderer.ts     PixiJS RigView（零件 / 骨骼叠加 / 拖影）、相机
    canvas-export.ts 交付渲染（Canvas 2D，透明背景，可分倍率）
    exporter.ts     character.json 生成与解析、zip 打包
  ui/
    app-shell.ts    顶部导航、身份切换、项目选择（Web Component）
    projects-view.ts
    workbench-view.ts
    stage-view.ts   PixiJS 画布、关节拖拽、搭骨、批注落点
    timeline-view.ts
    review-view.ts
    compare-view.ts
tests/
  unit.test.mjs     核心逻辑单测
  workbench.e2e.ts  端到端流程
```

## 交互速查

| 操作 | 快捷方式 |
| --- | --- |
