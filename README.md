# 菇棚层架与设备三维布置交付系统

面向菌菇合作社的纯前端交付系统:客户在棚区图纸上下需求单,制作员逐棚做三维布置,主管审核打包。数据全部存在浏览器 localStorage,无需后端。

## 技术栈

- Svelte 5(runes)+ Vite 6
- three.js(OrbitControls / TransformControls)
- 零 UI 框架,原生 CSS

## 启动

```bash
npm install
npm run dev      # 开发,默认 http://127.0.0.1:5173(端口被占用时见 vite.config.js)
npm run build    # 生产构建到 dist/
npm run preview  # 预览生产构建
```

## 三种角色(登录页一键切换,演示无密码)

| 角色 | 能看到的页面与能力 |
| --- | --- |
| 客户 | 看板、我的项目、下需求单(菇棚数量/层数/单层承重/交期)、导出物料清单 |
| 制作员 | 看板、项目列表、逐棚三维布置、提交/返工重新提交 |
| 主管 | 看板、项目列表、审核台、整单退回、通过并打包交付 |

## 八个界面

1. **登录页** — 角色选择
2. **首页看板** — 各人待办、在审数量、本周交期,超期项目单独一栏
3. **下需求单** — 客户填菇棚数量、层数、单层承重、交期
4. **项目列表** — 按状态/交期筛选,超期项目独立栏
5. **项目详情** — 需求信息、逐棚布置卡片、BOM、碰撞汇总、时间线
6. **三维布置页** — 核心工作台(见下)
7. **主管审核页** — 逐棚只读三维查看、碰撞告警与清单、退回/通过
8. **交付包页** — 交付信息、版本号、交付时间、导出 JSON/CSV、完整时间线

## 三维布置规则

- 设备库:层架、托盘、加湿管道、环流风机、采光灯(立柱为棚体结构,预置不可删)
- 点选物体出现变换手柄,平移吸附 **0.5m 网格**,旋转吸附 **90°**
- 层架强制贴地,禁用 Y 轴移动
- 拖动时实时 AABB 碰撞检测,以下情况物体**立即变红并写明原因**:
  - 压到棚体立柱
  - 与其他设备包围盒碰撞
  - 越出棚区边界
  - 层架未贴地
  - 同投影位置叠放 **超过 4 层**
- 一键俯视图:显示层架编号与每条走道净宽(低于 1m 标红),可导出 PNG
- 有任何违规时禁止提交审核

## 业务规则

- 主管整单退回必须填写原因,**计一次返工**,每个棚各自累计
- 同一棚返工 **超过 2 次** 在项目详情和列表中标红
- 审核通过自动打包:生成交付包编号 `PKG-...`、记录交付时间、版本号自增(v1.0 → v1.1 …)
- 物料清单自动汇总:层架(套)、托盘(个)、加湿管道(米)、风机(台)、灯具(盏)
- 所有操作写入时间线,带操作人与时间

## 数据与导出

- 存储键:`localStorage["mushroom-delivery-v1"]`
- 导出:
  - 交付包 JSON — 含需求、BOM、全部物体坐标/旋转/尺寸、告警、时间线
  - 物料清单 CSV — 全项目汇总 + 各棚明细(带 BOM,Excel 可直接打开)
  - 俯视 PNG — 三维视口截图

## 测试

```bash
npm run dev &      # 先启动 dev server(端口见下)
node tests/smoke.mjs   # 端到端:下单→布置→碰撞→退回→返工→打包→导出,20 项断言
node tests/rules.mjs   # 几何规则:叠层/越界/贴地/返工标红,6 项断言
```

> 测试默认访问 `http://127.0.0.1:8391`,与 `vite.config.js` 的 `server.port` 保持一致;
> 本机 5173 常被其他 Vite 应用占用,故固定到冷门端口并开启 `strictPort`。
> 测试依赖 `playwright`(本机 Chrome,`--no-save` 安装,不写入运行依赖)。
