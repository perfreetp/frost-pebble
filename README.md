# 分布式光伏屋面排布设计工具

浏览器内直接完成「屋面导入 → 禁布区识别 → 三维拖板排布 → 自动校核 → 多版对比 → 交付物导出」的单页应用，替代 CAD 画完靠人眼核遮挡的流程。

## 技术栈

- **Vite + React 19 + TypeScript**（严格模式）
- **Three.js**：三维屋面、贴坡渲染、InstancedMesh 批量组件、框选/拖拽交互
- **Zustand**：编辑状态；**Dexie (IndexedDB)**：屋面、方案、组件库本地持久化
- **dxf-parser**：CAD DXF 导入，按图层名自动识别四类禁布区
- 无后端，全部数据留在浏览器本地

## 启动

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm test           # 引擎 + DXF 共 37 项冒烟测试
```

首次打开自动载入一个带女儿墙/天窗/风机基础/排烟井的示例厂房屋面，可直接体验全流程。

## 四个界面

| 界面 | 能力 |
| --- | --- |
| 屋面列表 | 导入 DXF（图层识别禁布区、mm/m 单位自动换算）、屋面卡片管理、删除 |
| 排布编辑 | 组件库点选/拖拽、双击布板、横纵间距自动吸附、贴坡/平屋面支架倾角、一键自动排布、框选、整排批量复制、旋转、参数侧栏实时调参 |
| 校核结果 | 红色（必须处理）/黄色（警告）问题分类明细表、组串编号表、容量与 25 年收益估算 |
| 方案对比 | 最多 4 版同屏对比、最优指标星标、每版独立导出三种交付物 |

## 核心工程规则

- **禁布区识别**：DXF 图层名含 `女儿墙/parapet`、`天窗/skylight/采光`、`风机/fan/风帽`、`排烟/烟道/井/shaft` 自动归类；支持 LWPOLYLINE / POLYLINE / LINE 断线拼环 / CIRCLE；未识别图层名回传提示
- **不硬塞**：自动排布和批量复制逐格做合法性检查（出屋面、女儿墙退距、障碍碰撞、组件重叠），不合法即跳过并汇总原因，绝不强行放置
- **红色问题**：超出屋面、压到女儿墙/禁布区或退距不足、朝向偏差超限、组件重叠
- **黄色警告**：冬至指定真太阳时前后排阴影间距不足。太阳高度角/方位角按纬度与时角解析，间距 `D = H/tan(h)·cos(γ)`
- **组串编号**：按屋面 → 排（v 坐标聚类）→ 排内 u 排序自动生成 S001…，支持指定每串组件数
- **统计口径**：装机容量、屋面利用率（组件面积/屋面面积）、首年发电量、25 年衰减累计发电与收益、静态回收期
- **导出**：排布图 SVG（含禁布区填色、组件红黄绿状态、组串号）、组串表 CSV（带 BOM，Excel 直开）、业主收益估算 HTML（可打印 PDF）

## 目录结构

```
src/
  types.ts            领域模型
  store.ts            Zustand 全局状态
  lib/
    geometry.ts       多边形运算、贴坡坐标变换、太阳位置与阴影间距、吸附
    check.ts          单组件校核、组串划分、容量收益统计
    autoLayout.ts     网格自动排布、框选、批量复制
    dxf.ts            DXF 解析与禁布区图层识别
    exporters.ts      SVG / CSV / HTML 三种导出
    db.ts             IndexedDB 表结构
    sampleRoof.ts     内置示例屋面
  components/RoofViewer.tsx   Three.js 三维交互
  pages/              四个界面
scripts/              引擎与 DXF 冒烟测试
```

## 已知边界

- 屋面轮廓按单环多边形处理，暂不支持带洞多边形（洞以禁布区方式表达）
- 阴影按冬至单时刻、正南朝向的二维间距模型，未做逐时三维阴影体仿真
- DXF 仅读取 ENTITIES 段的二维几何，不解析块参照（INSERT）与三维实体
